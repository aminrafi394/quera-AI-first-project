## ۲. خوشه‌بندی و سیستم توصیه‌گر — `02_clustering_and_recommender.ipynb`

- **انتخاب ویژگی:** چهار مجموعه ویژگی با Silhouette، Calinski-Harabasz و Davies-Bouldin مقایسه شدند و «قیمت + مختصات UTM» برنده شد. هر ویژگی اضافه خوشه‌ها را بدتر کرد.
- **K-means با k = 10:** شهرهای دور هر کدام یک خوشه شدند و تهران به چهار سطح قیمت تقسیم شد.
- **انتخاب k:** زانوی Elbow با چشم دیده نمی‌شد. با KneeLocator، سه معیار کیفیت و مقایسه‌ی پروفایل خوشه‌ها **k = 7** انتخاب شد.
- **DBSCAN:** نقطه‌ی شروع eps از نمودار k-distance آمد و با جست‌وجوی شبکه‌ای، `eps=0.45` و `min_samples=1000` به **۳ خوشه‌ی معنادار** رسید: تهران-کرج-اصفهان، مشهد و شیراز. ۱۰٪ داده نویز شد و بیشترش ملک لوکس بود.
- **توصیه‌گر:** برای یک آگهی، نزدیک‌ترین آگهی‌های همان خوشه و همان نوع ملک را پیشنهاد می‌دهد. برای کاربری که بودجه و موقعیت دلخواهش را می‌دهد هم خوشه‌ی او را پیش‌بینی می‌کند و آگهی‌های مناسب را برمی‌گرداند.

## ۳. پیش‌بینی قیمت

| | اجاره — `03_rent_prediction.ipynb` | فروش — `04_sale_price_prediction.ipynb` |
|---|---|---|
| هدف | `log1p(rent_value)`، اجاره‌ی مسکونی و تجاری | `log1p(price_value)`، همه‌ی آگهی‌های فروش |
| تقسیم داده | ۸۰ / ۱۰ / ۱۰، با `random_state=42` | ۶۴ / ۱۶ / ۲۰، با `random_state=42` |
| مدل | XGBoost (۳۰۰۰ درخت، عمق ۱۰) | XGBoost با early stopping روی Validation |
| ویژگی‌های کلیدی | رهن، متراژ، شهر، محله و نسبت‌های محله‌ای/شهری | متراژ، شهر (Target Encoding)، فاصله تا مرکز شهر، سن بنا، امکانات |
| **R² روی Test** | **0.602** (Validation: 0.612) | **0.606** (Validation: 0.608) |
| MAE و MSE روی Test | MAE = 0.685، MSE = 1.240 (مقیاس لگاریتمی) | MAE ≈ ۱٫۳۶ میلیارد تومان. MSE و معادل لگاریتمی در نوت‌بوک گزارش می‌شوند. |

**نکته‌های تفسیری**

- در هر دو مدل، تمام انتخاب‌های ویژگی و پارامتر فقط با Validation انجام شده و Test یک بار، برای مدل نهایی، استفاده شده است.
- همه‌ی آمارهای گروهی فقط از Train ساخته شده‌اند تا نشت داده رخ ندهد.
- مدل اجاره **رهن همان آگهی** را به‌عنوان ورودی می‌گیرد. این نشت نیست، چون رهن پیش از اجاره در آگهی معلوم است، ولی بخش بزرگی از دقت از همین ستون می‌آید. نوت‌بوک ۳ مدل بدون رهن را هم برای مقایسه آموزش می‌دهد.
- مدل فروش ۵٪ پایین و بالای قیمت‌ها را حذف کرده است، پس معیارهایش برای قیمت‌های «معمول» معتبرند.
